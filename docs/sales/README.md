# 영업 자료

프리세일즈가 만들고, 담당 PO 가 사실 확인하고, 대표가 승인한 뒤 확정된다.

| 파일 | 내용 |
|---|---|
| `제품소개.md` | 무엇을 하는 제품인가 |
| `데모시나리오.md` | 무엇을 어떤 순서로 보여줄 것인가 |
| `FAQ.md` | 자주 나오는 질문과 답 |
| `기술답변.md` | 기술 실사 대응 |

## 원칙

**제품에 없는 것은 쓰지 않는다.** 모든 기능 주장은 코드나 문서에서 확인한 것이어야 한다.
아직 없지만 계획된 것은 "예정" 이라고 명시한다. 계획을 현재형으로 쓰지 않는다.

이 문서들은 고객에게 나간다. 틀리면 조직이 거짓말을 한 것이 된다.
